# Decision Log

> 本文件是 `product-investment-review` 的历史档案，也是它**唯一的不可复制资产**。
> 模型有通用推理能力，但它不拥有你的历史——这个文件的全部意义就在这里。
>
> **规则：只追加，不修改历史条目。** 判断错了也要留着，错判比正确判断更有校准价值。

## 条目格式（Decision Ledger）

> 一条记录不是「做了什么决定」，而是完整的
> **Decision → Hypothesis → Evidence → Investment → Gate → Outcome → Prediction Error**。
> 其中 **Prediction 必须在写下的那一刻登记**，事后不得修改——
> 没有预登记的预测，事后永远能被解释成「我早就知道」。

```markdown
### YYYY-MM-DD | <项目名>

**Decision**
- Verdict: 🟢 / 🟡 / 🔵 / 🔴
- 一句话理由:
- Founder Fit: 明显优势 / 明显缺口 / 致命缺口 / 尚未验证项
  （逐项列能力 + 证据强度：真实资产 / 弱证据 / 未知 / 无证据——**不给分数**）

**Hypothesis**
- 成立所依赖的核心假设（哪一条错了，整个项目就不成立）

**Investment**
- 本轮批准: X 小时 / Y 元（硬上限）
- 投在哪里:
- Gate: 达到什么标准算通过（可判定）
- Kill Line: 达不到 → 退回哪一步 / 杀掉（预先声明，事后不得改口）

**Prediction**（登记于写下时，事后不得修改）
- 到 YYYY-MM-DD，<具体可判定的结果>
- 若未出现 → 本次判断记为错误，并写明错在哪一格

**Outcome**（重跑时填，仅追加）
- 实际结果:
- Prediction Error: 命中 / 未命中（**未命中更有价值**）
- 判断对了吗: 对在哪一格 / 错在哪一格
- 这次学到什么:
- 死亡/停滞位置: 验证前 / 第二个功能 / 上线后无人用 / 从未上线 / —
```
